# UKIN - Media Pembelajaran Interaktif Struktur Data

Media Pembelajaran Interaktif Berbasis Web untuk Mata Pelajaran Informatika Fase E (Kelas X) SMA Negeri 4 Yogyakarta.

## 📌 Materi Pokok
Struktur Data Standar:
- **Array / List**: Penyimpanan linier dengan akses langsung berbasis indeks.
- **Stack (LIFO - Last In First Out)**: Simulasi tumpukan data (Push, Pop, Top).
- **Queue (FIFO - First In First Out)**: Simulasi antrean data (Enqueue, Dequeue, Front, Rear).

## 🚀 Fitur Utama
- **Materi Handbook Lengkap**: Konsep, karakteristik, dan analisis kasus kontekstual sehari-hari.
- **Simulator Interaktif**:
  - Simulasi Tumpukan Piring (Stack)
  - Simulasi Antrean Kantin (Queue)
  - Simulasi Direct Access Loker Sekolah (Array)
  - Simulasi Fitur Undo (Ctrl+Z) Microsoft Word (Kasus D)
- **LKPD Digital Kolaboratif (Aktivitas 1, 2, & 3)**: Dilengkapi penyimpanan draf lokal dan ekspor berkas PDF resmi sesuai RPP Lampiran III.
- **Asesmen Pembelajaran**: Pra-Tes (Pre-Test) dan Pasca-Tes (Post-Test) 6 butir soal pilihan ganda standar RPP Lampiran IV beserta kalkulasi Gain Score dan tindak lanjut (Pengayaan / Remedial KKTP = 75).
